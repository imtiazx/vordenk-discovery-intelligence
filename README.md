# Vordenk - Discovery Intelligence

AI-native discovery for enterprise transformation. This repository contains the
hackathon slice of the long-term Vordenk Enterprise Transformation OS vision.

It turns workshop conversation evidence into an evidence-linked, cross-session
business model: extracted facts with source references, discovered gaps,
contradictions and prioritised questions, rendered as an editable process visual,
with human validation at every consequential step.

Built during the Meta Global AI Developer Hackathon (Oct 27 – Nov 4, 2026),
Indie Developer track, "Build for Your World" theme.
